FreePBX 16/17 fast call log analyzer. \
Module language RU.

#Callanalyzer: \
Summerize call trace \
Full current call log download 

#Setup: \
1.Go to https://github.com/rstayalive/callanalyzer/releases/latest \
2.Copy url to latest zip \
3.FreePBX web interface setup: Go to Admin > Module Admin > Upload Modules to install the module. \
4.Select Type - Download (From web) \
5.Paste url with zip archive from 2 \
6.Click button - Download (From Web) \
7.Go to Admin - Module Admin - find section Reports - find module callanalyzer - select install - click button Process - click button Confirm - click Confirm - click button Apply config at the top of web page. Done.

#Module usage \
Check module - Reports - Call analyzer
Select date
Enter phone number for search
Click button search
